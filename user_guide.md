# Руководство пользователя — Терминал охранника

## Назначение
Приложение предназначено для регистрации входов/выходов сотрудников по пропускам, выдачи временных пропусков гостям и управления парковочными талонами.

## Установка
1. Установить Python 3.11+.
2. Установить зависимости: `pip install -r requirements.txt`.

## Запуск
`python -m src.main`

При первом запуске рядом с проектом создаётся база `guard_terminal.sqlite3`.

## Вкладка «Сотрудники»
1. Введите номер пропуска, имя, фамилию.
2. Нажмите «Вход» — сохранится время входа.
3. Для выхода: введите номер пропуска и нажмите «Выход» — обновится время выхода.

Ограничение: нельзя выполнить повторный «Вход», пока не зарегистрирован «Выход».

## Вкладка «Гости»
1. Введите ID временного пропуска (любая строка 3–32 символа), имя, фамилию.
2. Укажите «Действует (часы)» (1–72).
3. Нажмите «Вход» — создастся запись гостевого посещения.
4. Для выхода: введите ID и нажмите «Выход».

Проверка просрочек:
- Кнопка «Проверить просрочки» показывает предупреждение для гостей, которые не вышли вовремя.
- Также приложение автоматически проверяет просрочки каждые 30 секунд.

## Вкладка «Парковка»
1. Укажите тип: `employee` или `guest`.
2. Для `employee` обязательно укажите номер пропуска.
3. Укажите номер автомобиля.
4. Нажмите «Выдать талон».

Правила:
- Количество мест задаётся в «Настройки».
- Если мест для сотрудников не хватает, сотрудник может занять свободное гостевое место.
- Если гостевых мест нет, система предлагает подождать или приехать в другой день.

Закрытие талона:
- Выберите талон в списке и нажмите «Закрыть выбранный».

## Валидация
- Номер пропуска/ID: 3–32 символа (буквы/цифры/дефис)
- Имя/Фамилия: 2–40 символов (рус/лат) или дефис
- Номер авто: 4–16 символов
